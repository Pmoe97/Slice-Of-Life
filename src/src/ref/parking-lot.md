# Parking lot — off-hand ideas, not yet scoped to any plan

Not a plan. Not a backlog with priorities. Just a place to write down a
pitch the moment it occurs so it survives a context handoff instead of
being remembered later as "a lot of potential to be great or awful" with
the actual content gone (see the actions-and-activities-overhaul-plan's Q1
for exactly that failure mode — this file exists so it doesn't happen
again).

Add an entry the moment an idea comes up mid-conversation about something
else. Don't design it here — one paragraph, enough that future-you (or a
future session) can pick it back up. When an idea gets picked up for real,
move its entry to the plan that adopts it (or start a new plan doc for it)
and delete it from here.
